Machine identities — service accounts, API keys, certificates — now significantly outnumber human identities in most enterprise environments, and are frequently far less governed.

## Key points

- Service accounts are often created for a specific one-time task and then never decommissioned, accumulating unused but still-valid access over time.
- Unlike human accounts, machine identities don't naturally trigger the same offboarding processes when the associated project or team changes.
- Automated discovery tools that inventory all machine identities across cloud and on-prem environments are a prerequisite to actually governing them.

## The takeaway

You can't secure what you haven't inventoried — and most organizations have never fully inventoried their non-human identities.
