DNS ist eine grundlegende Voraussetzung für das Funktionieren des Internets. Daher haben DNS-basierte Angriffe und Abwehrmaßnahmen im Verhältnis zu ihrer Sichtbarkeit überproportionale Auswirkungen.

## Wichtigste Punkte

- DNS-Filterung kann den Zugriff auf bekannte bösartige Domains blockieren, bevor überhaupt eine Verbindung hergestellt wird, und so viele Angriffe abwehren, bevor sie ein Endgerät erreichen.
- DNS-Tunneling ist eine Technik, mit der Angreifer Daten ausschleusen oder die Befehls- und Steuerkommunikation aufrechterhalten und als gewöhnlichen DNS-Verkehr tarnen.
- DNSSEC versieht DNS-Antworten mit einer kryptografischen Überprüfung und schützt so vor DNS-Spoofing und Cache-Poisoning.

## Fazit

DNS-Sicherheit wird leicht übersehen, weil DNS eine unsichtbare Infrastruktur ist, an die die meisten Menschen nie denken — bis sie ausgenutzt wird.
