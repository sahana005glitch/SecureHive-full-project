Jährliche allgemeine Sicherheitsschulungen schneiden nachweislich schlecht ab — für eine Verhaltensänderung braucht es einen grundlegend anderen Ansatz.

## Wichtige Punkte

- Häufige, kurze Schulungen fördern laut den meisten Studien zu Security Awareness die tatsächliche Behaltensleistung und Verhaltensänderung besser als jährliche Ganztagsveranstaltungen.
- Simulierte Phishing-Tests mit sofortigem, nicht strafendem Feedback schulen das Erkennen von Angriffen wesentlich wirksamer als reine Vorträge.
- Eine wirklich einfache Meldemöglichkeit (etwa eine Schaltfläche mit einem Klick) und positive Bestärkung erhöhen die Meldequote stärker als die Bestrafung von Fehlern.

## Fazit

Security Awareness wirkt, wenn sie als fortlaufendes Programm zur Verhaltensänderung behandelt wird — nicht als jährliche Compliance-Pflichtübung.
