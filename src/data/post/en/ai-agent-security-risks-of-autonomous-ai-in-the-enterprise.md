As organizations deploy AI agents with the ability to take real actions — not just answer questions — the security model for those agents needs to catch up.

## Key points

- AI agents with access to internal tools or APIs represent a new kind of non-human identity that traditional IAM systems weren't designed to govern.
- Prompt injection attacks can manipulate an AI agent into taking unintended actions by hiding malicious instructions in content the agent processes.
- Least-privilege principles apply directly to AI agents: an agent should only have access to the specific tools and data its task requires, nothing more.

## The takeaway

AI agent security is less about a fundamentally new discipline and more about applying identity and access management fundamentals to a new class of identity.
