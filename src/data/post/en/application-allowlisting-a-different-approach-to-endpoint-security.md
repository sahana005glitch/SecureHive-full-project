Rather than trying to detect and block malicious software (a constantly evolving list), application allowlisting only permits explicitly approved software to run at all.

## Key points

- This approach is particularly effective against unknown or novel malware, since anything not explicitly approved simply won't execute, regardless of whether it's detected as malicious.
- The operational tradeoff is maintenance overhead — every legitimate new application or update needs to be added to the allowlist before it will run.
- Modern allowlisting tools reduce this burden through trusted publisher policies and automated approval workflows for common software update patterns.

## The takeaway

Allowlisting flips the traditional security model from 'block what's bad' to 'permit only what's known good' — a fundamentally stronger position when implemented well.
