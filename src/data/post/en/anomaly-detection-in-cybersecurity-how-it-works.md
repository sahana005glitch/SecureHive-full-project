Anomaly detection systems learn a baseline of normal behavior and flag deviations, catching threats that don't match any known signature.

## Key points

- Behavioral baselines need to account for legitimate variation (end-of-quarter data access spikes, for example) to avoid excessive false positives.
- Anomaly detection is particularly effective against insider threats and compromised accounts, since the malicious activity often deviates from that user's normal pattern.
- These systems require an initial learning period and ongoing tuning — a poorly tuned anomaly detection system either misses real threats or drowns analysts in false alerts.

## The takeaway

Anomaly detection catches what signature-based tools structurally can't — the previously unseen attack — at the cost of requiring careful tuning to be actually useful.
