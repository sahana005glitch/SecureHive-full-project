Just-in-time access grants elevated permissions only for the specific duration needed, then automatically revokes them — rather than leaving privileged access standing indefinitely.

## Key points

- Standing privileged access is a prime target for attackers precisely because it doesn't require timing an attack around a specific access window.
- JIT access typically involves an approval workflow (automated or manual) triggered by a specific request, with time-bound grants that expire automatically.
- This approach significantly reduces the attack surface available at any given moment, since most privileged access simply doesn't exist until actively requested.

## The takeaway

Just-in-time access embodies a core zero trust principle in a very concrete way: access exists only when actively needed, not by default.
