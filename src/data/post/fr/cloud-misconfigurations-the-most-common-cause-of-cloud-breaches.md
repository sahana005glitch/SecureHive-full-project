La plupart des violations de données cloud rendues publiques sont dues à des erreurs de configuration — le plus souvent des compartiments de stockage laissés accessibles au public — plutôt qu'à une exploitation sophistiquée.

## Points clés

- Les paramètres par défaut des plateformes cloud ont évolué vers davantage de sécurité, mais les ressources anciennes configurées il y a plusieurs années ne bénéficient souvent pas de ces améliorations.
- Les outils de gestion de la posture de sécurité du cloud (CSPM) analysent en continu les environnements cloud à la recherche d'écarts par rapport aux bonnes pratiques de référence.
- Le modèle de responsabilité partagée signifie que le fournisseur cloud sécurise l'infrastructure sous-jacente, mais que le client reste responsable de la configuration des éléments qu'il y déploie.

## À retenir

Les violations dans le cloud sont rarement dues à une insécurité intrinsèque du cloud : elles résultent très majoritairement d'erreurs de configuration qui passent inaperçues jusqu'à ce qu'il soit trop tard.
