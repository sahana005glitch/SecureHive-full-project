Dans la plupart des environnements d’entreprise, les identités machine — comptes de service, clés d’API et certificats — sont désormais bien plus nombreuses que les identités humaines et sont souvent beaucoup moins gouvernées.

## Points clés

- Les comptes de service sont souvent créés pour une tâche ponctuelle, puis jamais supprimés. Ils accumulent ainsi des accès inutilisés mais toujours valides.
- Contrairement aux comptes humains, les identités machine ne déclenchent pas naturellement les mêmes processus de départ lorsque le projet ou l’équipe concernée change.
- Les outils automatisés de découverte qui recensent toutes les identités machine dans les environnements cloud et sur site sont indispensables à leur gouvernance.

## À retenir

Il est impossible de sécuriser ce qui n’a pas été inventorié — et la plupart des organisations n’ont jamais dressé un inventaire complet de leurs identités non humaines.
