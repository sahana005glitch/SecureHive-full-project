Getting an initial foothold is often just the first step for an attacker — lateral movement describes how they expand access from that single compromised system to more valuable targets.

## Key points

- Attackers often use legitimate administrative tools already present on the network (a technique called 'living off the land') specifically to avoid detection by security tools looking for malware.
- Network segmentation limits lateral movement by ensuring a compromised system in one segment can't directly reach systems in another.
- Monitoring for unusual authentication patterns — a user account logging into systems it's never accessed before — is a key detection technique.

## The takeaway

Preventing initial compromise is important, but assuming it will eventually happen and limiting lateral movement is what actually contains the damage.
