Despite being a well-understood vulnerability class for over two decades, SQL injection still appears regularly in security audits and breach reports.

## Key points

- SQL injection happens when user input is concatenated directly into a database query instead of being properly parameterized.
- Parameterized queries (prepared statements) eliminate the vast majority of SQL injection risk with minimal code changes.
- Automated scanners catch many SQL injection flaws, but business-logic-specific injection points often require manual testing to find.

## The takeaway

SQL injection persists mostly in legacy code and rushed development — the fix has been known and cheap for years.
